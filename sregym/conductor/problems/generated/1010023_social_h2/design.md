A vendor-bundled binary decoder is registered in the ordinary nginx startup block through Lua's preload registry. Bundling a compatibility runtime alongside gateway configuration is a realistic incremental client migration. The original runtime and generated clients on disk remain correct, and the bundled runtime preserves standard message constants, byte packing, framing and request generation. Its schema metadata cache has two semantic defects. It indexes field descriptors by numeric field ID across nested structs; when a nested field has a different type, it treats the tag as an unknown extension and skips it. Thrift IDs are local to the enclosing struct, so this loses legitimate nested fields. It also translates the single struct item descriptor in a generated list schema into a fixed extent of one. Actual wire list lengths, including zero, are runtime data and cannot be validated against that schema extent. The same cache subsequently treats other observed list extents as invariant for a wire element type.
